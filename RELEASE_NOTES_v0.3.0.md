## Highlights

SkillGuard 0.3.0 focuses on **trust verification and developer workflows**, not on
maximizing rule count:

- `skillguard compare` — report-to-report security regression with stable fingerprints
- Baseline accept/annotate workflow (findings never rewritten; critical suppressions blocked by default)
- Reproducible audit manifests + signing guidance (cosign/gpg/minisign — no custom crypto)
- Sandbox strict mode: digest-pinned images, fail-closed verification
- Pre-commit + GitHub Actions examples / reusable workflow
- Third-party comparison harness without superiority claims

## Install

```bash
git clone https://github.com/R2W1cs/Skillguard.git
cd Skillguard
pip install -e ".[dev]"
skillguard version
```

## Verify quickly

```bash
skillguard scan tests/fixtures/benign/hello-world --quiet
skillguard scan tests/fixtures/malicious/secret-exfil --format json -o report.json --fail-on high; echo $?
skillguard benchmark run --dataset adversarial --json-out benchmarks/adversarial-latest.json
```

## Honesty reminders

- A clean scan is **not** a safety proof
- Synthetic benchmark scores are **maintainer-run** and separate from real-world evaluation
- No claim of superiority vs NVIDIA SkillSpector, Cisco skill-scanner, or Snyk agent-scan

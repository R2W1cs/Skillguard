# Responsible disclosure

Report vulnerabilities in **SkillGuard itself** (for example: secret leakage in
reports, path traversal during discovery, unsafe sandbox defaults) privately.

## How to report

1. Prefer a private GitHub security advisory on
   [R2W1cs/Skillguard](https://github.com/R2W1cs/Skillguard/security/advisories/new)
2. Or contact the maintainers privately — do not open a public issue with exploit details

Include:

- Affected version / commit
- Reproduction steps
- Impact assessment

Full policy: [SECURITY.md](https://github.com/R2W1cs/Skillguard/blob/master/SECURITY.md)

## Supported versions

Security fixes target the latest released version on the default branch.
